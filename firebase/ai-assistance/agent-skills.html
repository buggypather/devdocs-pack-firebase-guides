Firebase agent skills

Firebase agent skills (GitHub) are portable, self-contained modules of Firebase-specific knowledge, instructions, and workflows. They're designed to help AI assistants understand Firebase best practices and execute complex tasks with higher accuracy and lower token cost. For a full list of the Firebase agent skills, see Available skills.

Get started

Firebase agent skills work with any AI assistant that supports skills, including Antigravity, Claude Code, Codex, and Cursor.

Install Firebase agent skills

In most cases, Firebase agent skills can be installed in your preferred editor with a single command:

Antigravity

  • Option 1: Global-level access

    Firebase agent skills are included in the Firebase plugin in the Antigravity Marketplace (and as a Build with Google integration bundle). Install the plugin using any of the following options:

    • From the Antigravity Marketplace: Click Customizations, select the Marketplace tab, and then click + on the Firebase plugin card.
    • In Antigravity CLI: Run /plugin install firebase@agent-marketplace (or run /plugin and install Firebase from the Discover tab). Plugins installed in Antigravity also sync automatically to Antigravity CLI.
    • During onboarding: Select the checkbox for the Firebase stack.

  • Option 2: Project-level access

    Run the following command in your project's directory:

    npx skills add firebase/agent-skills --agent=antigravity

Claude Code

Run the following commands in your terminal:

claude plugin marketplace add firebase/agent-skills
claude plugin install firebase@firebase

Codex

  • Option 1: Codex terminal

    Run the following commands in your terminal:

    codex plugin marketplace add firebase/agent-skills
codex plugin add firebase@firebase

  • Option 2: Codex app

    1. Complete the following tasks one time:

      1. Register through the terminal:

        codex plugin marketplace add firebase/agent-skills

      2. Fully restart the Codex app.

      3. Open Plugins.

      4. Select the Firebase marketplace/source.

      5. Open Firebase and click + Install.

    2. Start a new task.

    3. Type @Firebase to select the plugin, or ask Codex to perform a Firebase task.

Cursor

  • Option 1: Install the plugin directly from the Cursor Marketplace.

  • Option 2: Run the following command in your terminal:

    npx skills add firebase/agent-skills --agent=cursor

Other agents

Run the following command in your terminal:

npx skills add firebase/agent-skills
Important: Agent skills are actively developed. To ensure your AI assistant always has the latest Firebase features, best practices, and security recommendations, be sure to regularly update your skills.

Update Firebase agent skills

You can get all available updates and clean up out-of-date skills by running the update command:

Antigravity

Plugins installed from the Antigravity Marketplace (or enabled during onboarding) are managed and updated automatically by Antigravity.

If you installed agent skills using the npx command, you can get all available updates by running the update command:

npx skills update --all

Claude Code

claude plugin marketplace update firebase

Codex

Refresh the repository snapshot:

codex plugin marketplace upgrade firebase

If a refreshed version is not picked up, reinstall the plugin:

codex plugin remove firebase@firebase
codex plugin add firebase@firebase

Cursor

npx skills update --all

Other agents

npx skills update --all

Use Firebase agent skills

AI assistants are designed to use skills automatically whenever they detect that a skill's description matches your current request. However, skills can also be manually invoked. This is often done by typing / in the agent chat and searching for the skill name.

Core components of a skill

Each agent skill is a specialized package centered around a SKILL.md definition that provides the AI assistant with the following components:

  • Specialized instructions: Detailed guidance on achieving specific tasks, such as implementing Firebase Authentication or provisioning a Cloud Firestore database.
  • Best practices: Built-in security and performance patterns to ensure your app follows Firebase recommendations from the start.
  • Automation scripts: Executable code that allows your AI agent to perform local environment setup or configuration automatically.

Benefits to using skills

Using agent skills reduces the manual effort of searching documentation while improving the efficiency of your AI interactions.

Reduced token costs

Conventional AI integrations often load massive amounts of documentation upfront, which consumes significant tokens and increases session costs. Agent skills use progressive disclosure to minimize this overhead:

  • The agent initially only "scans" brief metadata to see if a skill is relevant.
  • Detailed instructions and resources are only loaded when the agent determines they're necessary for your specific task.

AI-guided implementation

Instead of manually searching through documentation, you can describe your intent in natural language. Skills guide your AI assistant to perform tasks such as the following:

  • Add a sign-in screen to my web app.
  • Save my to-do list items to a database.
  • Help me deploy my new web app.

For a full list of the Firebase agent skills, see Available skills.

Use skills alongside the Firebase MCP server

Agent skills are designed to complement the Firebase MCP server:

  • Firebase MCP server: Designed for AI-assisted development workflows, enabling AI assistants to interact with your Firebase projects, resources, and data programmatically.
  • Firebase agent skills: Provide the quick instructions and recommended practices that tell an agent how to perform Firebase tasks through token-efficient progressive disclosure. They educate the agent on how to use tools like the Firebase CLI and MCP server effectively.
Note: To get the most out of Firebase agent skills, we recommend also installing the Firebase MCP server. Having both tools installed allows the agent to use MCP tools to complete complex tasks more efficiently.

Available skills

Firebase provides a suite of skills for core products. Skills for additional Firebase products and features are coming soon!

Skill Description
firebase-ai-logic-basics Helps integrate Firebase AI Logic (Gemini API) into web applications. Covers setup, multimodal inference, structured output, and security.
firebase-analytics Assists with getting started and measuring screenviews for Google Analytics in iOS and Android apps.
firebase-app-hosting-basics Streamlines the process of deploying and managing modern web frameworks like Next.js and Angular that require backend support using Firebase App Hosting.
firebase-auth-basics Helps you implement secure sign-in with Firebase Authentication, manage your user base, and protect your data using authentication-based Security Rules.
firebase-basics Assists with adding Firebase to your app for the first time, and learning general platform workflows.
firebase-crashlytics Assists with setting up, instrumenting, and validating Firebase Crashlytics in iOS and Android apps.
firebase-local-env-setup Assists with setting up your local environment, including the Firebase CLI and Firebase Local Emulator Suite, for Firebase development.
firebase-data-connect-basics Helps implement and manage Firebase SQL Connect to build type-safe, PostgreSQL-backed applications using GraphQL.
firebase-firestore-standard Covers the essentials of Cloud Firestore, including database provisioning, writing Security Rules, and performing data operations with the SDK.
firebase-firestore-enterprise-native-mode Covers the essentials of Cloud Firestore in Enterprise edition Native mode, including database provisioning, writing Security Rules, and performing data operations with the SDK.
firebase-hosting-basics Assists with deploying static websites, Single Page Apps (SPAs), and simple microservices to Firebase Hosting.
firestore-security-rules-auditor Assists with auditing Cloud Firestore Security Rules for common vulnerabilities and best practices.
firebase-remote-config-basics Assists with Remote Config template management, including setting up Remote Config, managing feature flags, SDK usage, and updating app behavior dynamically.
