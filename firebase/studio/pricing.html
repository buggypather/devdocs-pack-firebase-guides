Firebase Studio pricing, quotas, and limits

Important: As of June 22, 2026, new workspace creation is disabled. The workspace limits and quotas listed on this page are no longer applicable for new registrations or creating new workspaces.

Access to Firebase Studio is available at no cost, but you can increase the number of workspaces you can create by joining the Google Developer Program.

Certain integrations (like Firebase App Hosting) may require a Cloud Billing account.

Important notes on Flutter and React Native + Expo workspaces

If you're not subscribed to a Google Developer Program premium plan, you're limited to two total workspaces across both Flutter and React Native + Expo. This means you can have a maximum of:

  • Two Flutter workspaces OR
  • Two React Native + Expo workspaces OR
  • One Flutter and one React Native + Expo workspace

Once you have reached the maximum of two workspaces, you must delete an existing workspace before you can create a new one.

What if I already have more than two workspaces?

If you have more than two Flutter or React Native + Expo workspaces, you will retain access to them. However, you won't be able to create any new workspaces in these categories until you delete enough to fall under the two workspace limit.

To increase the number of Flutter and React Native + Expo workspaces you can create, join the Google Developer Program premium plan.

Cloud Billing and paid services

Certain integrations, such as Firebase App Hosting, may require a Cloud Billing account. If you create a Firebase project with Firebase Studio and link a billing account to that project, the following occurs:

  • The Firebase project is automatically upgraded to the pay-as-you-go Blaze pricing plan.
  • You will be charged for any usage of paid services beyond the no-cost quota.
  • Your Gemini Developer API usage is upgraded to the paid tier.
