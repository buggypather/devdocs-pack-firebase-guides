FieldReference

A reference to a field in a document, ex: stats.operations.

JSON representation 
{
  "fieldPath": string
}
Fields
fieldPath

string

A reference to a field in a document.

Requires:

  • MUST be a dot-delimited (.) string of segments, where each segment conforms to document field name limitations.
