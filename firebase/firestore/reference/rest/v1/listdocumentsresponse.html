ListDocumentsResponse

The response for Firestore.ListDocuments.

JSON representation 
{
  "documents": [
    {
      object (Document)
    }
  ],
  "nextPageToken": string
}
Fields
documents[]

object (Document)

The Documents found.
nextPageToken

string

A token to retrieve the next page of documents.

If this field is omitted, there are no subsequent pages.
