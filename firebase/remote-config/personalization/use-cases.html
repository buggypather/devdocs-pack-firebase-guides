What can you do with Remote Config personalization?

Remote Config personalization optimizes for Google Analytics events, so if you can trigger an event with meaningful parameters, you can create a personalization for it.

For the most useful results, you should choose an event that triggers often with alternative values that you expect to produce significant differences in outcomes. Personalization performs best when you have at least 10,000 users and over 1,000 triggering events per week (or conversions).

Explore some common ways you can personalize your app:

  • Optimize for ad impression revenue: Provide optional mini-games or features gated behind a full-page ad to maximize ad revenue without affecting user engagement.
  • Select the best ad placement for each user: Determine which ad location experiences the best response for individual users.
  • Optimize for ad frequency: Customize ad presentation cadence to determine which frequency results in the most user engagement.
  • Determine difficulty selection to maximize engagement: Automatically choose the right level of difficulty to engage individual players with varying skills.
